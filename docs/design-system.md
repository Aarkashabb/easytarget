# Дизайн-система EasyTarget: «Ночная смена»

Документ описывает визуальный язык сайта easytarget.com.ua и порядок переноса его с главной страницы на все остальные. Эталон реализации — главная (`hugo/layouts/index.html`, `hugo/assets/css/home-night.css`, `hugo/assets/js/home.js`), ветка `design/night-home`, PR #19.

Читать целиком перед любой правкой вёрстки. Если правило из документа конфликтует с существующим CSS, прав документ.

## 1. Идея

Сайт выглядит как работающая схема автоматизации: тёмный фон, тонкие линии, моноширинные метки, один сигнальный цвет для действий и голубой как цвет «данных». Инженерный инструмент, а не маркетинговый шаблон.

Чего на сайте быть не должно:

- градиентов (ни в фоне, ни в тексте, ни в кнопках, ни в рамках);
- скруглений у блоков, карточек и кнопок (исключение: теги-пилюли и переключатель языка);
- мягких серых теней под карточками и «подпрыгивания» карточек на наведение;
- заголовков секций по центру;
- сеток из трёх-четырёх одинаковых карточек с иконкой, заголовком и ссылкой «Дізнатися більше»;
- текстовых звёзд, кружков-аватаров, стоковых иллюстраций, эмодзи в интерфейсе;
- светлых секций. Весь сайт тёмный, включая статьи блога.

## 2. Токены

Все значения берутся из переменных. Жёстко прописанный цвет в новом коде — ошибка.

### Цвет

| Переменная | Значение | Назначение |
|---|---|---|
| `--n-bg` | `#070D18` | фон страницы |
| `--n-panel` | `#101C30` | фон карточек, панелей, полей |
| `--c-ink` | `#0B1424` | фон затемнённых полос (процесс, подвал) |
| `--n-text` | `#E9EEF5` | основной текст, заголовки |
| `--n-mut` | `#B9C2CF` | вторичный текст, описания |
| `--n-dim` | `#9AA7BA` | метки, подписи, даты (минимум для мелкого текста) |
| `--n-line` | `rgba(233,238,245,.16)` | линии, рамки |
| `--n-sig` | `#C8F03C` | сигнальный лайм: главная кнопка, акцент в H1, ссылки-действия, цены |
| `--n-sig-ink` | `#0E1B2E` | текст на лаймовом фоне |
| `--n-data` | `#3FD9FF` | «данные»: провода схемы, рамки узлов, метка платформы, наведение на кейс |

Правила:

- Лайм — только для действия или одного акцента на экран. Не красить им абзацы и фоны секций (исключение: финальный призыв).
- Голубой — только для элементов схемы и технических меток. Не для кнопок и не для ссылок в тексте.
- Свечение (`box-shadow: 0 0 24–40px` цветом лайма или голубого с прозрачностью 0.2–0.5) допустимо на узлах схемы, на наведении главной кнопки и карточки кейса. Больше нигде.
- Контраст текста не ниже 4.5:1. Цвета тусклее `--n-dim` для текста не использовать.

Старые переменные (`--c-text`, `--c-bg`, `--c-surface`, `--c-accent-*`, `--grad-accent`, `--r*`, `--shadow-*`) переопределены в `body.night` на значения выше, поэтому существующий CSS, который ими пользуется, перекрашивается сам.

### Шрифты

| Роль | Семейство | Где |
|---|---|---|
| Заголовки H1, H2 | `Unbounded` 700, `letter-spacing: -0.02em`, `line-height: 1.08–1.1` | `--n-disp` |
| Текст, H3, кнопки | `Inter` 400/500/600/700 | по умолчанию |
| Метки, номера, цены, даты, теги платформ | `JetBrains Mono` 500 | `--n-mono` |

- Все шрифты лежат в `hugo/static/fonts/`. Подключать с Google Fonts или CDN нельзя: CSP это блокирует.
- Unbounded широкий. H3 и ниже им не набирать. Длинные H1 статей: `clamp(26px, 3.4vw, 44px)`.
- Моноширинные метки: 11–13 px, `letter-spacing: .08em`, прописные.

### Размеры

| Что | Значение |
|---|---|
| H1 главной | `clamp(31px, 4.5vw, 62px)` |
| H2 секции | `clamp(24px, 3vw, 40px)` |
| H3 | 17–22 px, Inter 700 |
| Текст | 16–18 px, `line-height: 1.55` |
| Контейнер | 1200 px, поля 32 px (20 px до 860 px) |
| Секция | `padding: 96px 0` (64 px до 860 px), сверху линия `1px solid var(--n-line)` |
| Скругления | 0 (пилюли 999 px) |
| Рамки | 1 px `--n-line`; у кнопок-контуров и вкладок 1.5 px |
| Брейкпоинты | 1100 px, 860 px (основной мобильный) |

## 3. Компоненты

Готовые классы из `home-night.css`. Сначала использовать их, новые придумывать только если подходящего нет.

- **Заголовок секции** `.n-head`: слева, сверху метка `.n-idx` (номер секции или раздел), затем `h2`, затем абзац. Ширина до 760 px.
- **Кнопки**: `.btn.btn--primary` (лайм, тёмный текст, без тени), `.btn.btn--ghost` (контур). Высота не меньше 48 px. Одна главная кнопка на экран.
- **Строки** `.n-row` (номер, название, описание, стрелка): для любых списков услуг, возможностей, пунктов. Заменяют сетки карточек.
- **Прайс-строка** `.n-price`: название, пояснение, цена моноширинным лаймом. Для всех таблиц цен.
- **Карточка кейса** `.n-case`: скриншот 16:9 сверху, строка меток, заголовок, текст, ссылка. Лента `.n-cases` с прокруткой и привязкой.
- **Шаги** `.n-steps` / `.n-step`: линия сверху, номера моноширинным, выделенный шаг `.n-step--audit`.
- **Теги** `.tag`, `.tag--platform`: пилюли, перекрашены.
- **Аккордеон FAQ** `.faq__item`: оставлен, перекрашен токенами.
- **Финальный призыв** `.final-cta`: лаймовая полоса, тёмный текст, тёмная кнопка. Один раз на странице, в конце.
- **Закреплённая кнопка** `.n-sticky`: только до 860 px, показывается после первого экрана.
- **3D-схема** (`.n-scene`, `.n-board`, `.n-node`, `.n-wire`, `.n-pulse`): только на главной. На других страницах не повторять; допустим статичный фон-сетка `.n-grid` как декоративный мотив в шапке страницы.

Наведение: меняется цвет рамки, появляется свечение или сдвигается стрелка. Блоки не поднимаются и не масштабируются.

Движение: появление секций (`.reveal`) оставить как есть. Всё новое движение обязано отключаться при `prefers-reduced-motion: reduce`.

## 4. Телефон

Требование обязательное, проверяется на 375 px.

- Горизонтальной прокрутки страницы быть не должно. Широкие таблицы и ленты прокручиваются внутри своего блока.
- Касаемые элементы не меньше 44 px по высоте.
- Сетки сворачиваются в одну колонку, шаги — в две.
- Строки `.n-row` и `.n-price` перестраиваются: описание уходит под название.
- Никаких эффектов, завязанных на наведение, без альтернативы для касания.
- Текст статей на телефоне 17 px.

## 5. Статьи блога и длинный текст

Тёмный фон сохраняется. Чтобы читалось легко:

- колонка текста не шире 720 px;
- кегль 18 px (17 px на телефоне), `line-height: 1.7`, цвет `--n-text` с прозрачностью не ниже 0.9 (не чисто белый);
- H2 статьи: Unbounded, `clamp(22px, 2.4vw, 30px)`; H3: Inter 700, 20 px;
- ссылки в тексте: цвет `--n-text`, подчёркивание лаймом (`text-decoration-color: var(--n-sig)`), на наведение весь текст лаймом;
- цитаты: линия слева 2 px `--n-data`, без фона;
- код: `--n-panel`, рамка `--n-line`, JetBrains Mono;
- таблицы: линии `--n-line`, шапка моноширинным `--n-dim`, обёртка с `overflow-x: auto`;
- изображения: рамка 1 px `--n-line`, без скруглений.

## 6. Порядок переноса на остальные страницы

Работать в ветке `design/night-home` (или в ветке от неё), один коммит на шаг. Главную не ломать.

### Шаг 0. Сделать тему общей

1. В `hugo/layouts/_default/baseof.html` класс `night` у `<body>` поставить без условия.
2. Разделить `home-night.css` на два файла:
   - `assets/css/theme-night.css`: `@font-face` Unbounded, блок `body.night { … }` с токенами, раздел «shared pieces re-skinned», `.n-head`, `.n-idx`, кнопки, `.n-row`, `.n-price`, `.n-case`, `.n-steps`, финальный призыв, `.n-sticky`. Подключить в `partials/head.html` на всех страницах после `styles.css`.
   - `assets/css/home-night.css`: только первый экран (`.n-hero`, `.n-stage`, `.n-scene`, `.n-board`, узлы, анимации, вкладки) и `.n-about`. Подключается только на главной, как сейчас.
3. Предзагрузку шрифта Unbounded в `head.html` сделать для всех страниц.
4. Закреплённую кнопку `.n-sticky` и её скрипт перенести в общий шаблон, если она нужна на внутренних страницах (нужна на страницах услуг, цен, аудита, кейсов; в статьях блога не нужна).

После шага 0 открыть каждую группу страниц и записать, что сломалось. Дальше чинить по шаблонам.

Найти: `grep -nE "#[0-9a-fA-F]{3,6}\b|rgba?\(" hugo/assets/css/styles.css`. Каждое место, которое видно на странице, заменить на токен. Править в `theme-night.css` переопределением либо прямо в `styles.css` — на выбор, но одинаково во всём шаге.

## 7. Чего не трогать

- URL, `title`, `description`, H1, hreflang, канонические ссылки, `partials/schema.html`, `robots.txt`, `sitemap.xml`, `index.llms.txt`.
- Тексты в `content/`. Новый текст допустим только как метка интерфейса в `i18n/{uk,ru,en}.yaml`, сразу на трёх языках.
- CSP в `hugo/static/_headers`. Внешние скрипты, шрифты и стили не подключать.
- Аналитику в `head.html` и события в `site.js`.
- Ветку `main` напрямую. Только PR; слияние делает Иван.

## 8. Проверка после каждого шага

1. `cd hugo && hugo --minify --gc` без ошибок.
2. `python3 scripts/check_noindex_sitemap.py --build-dir hugo/public`, `check_404_page.py`, `check_www_redirect.py` проходят.
3. `hugo server`, затем в браузере страница шаблона на 1440 px и 375 px, на украинском и ещё одном языке:
   - нет светлых блоков, белых подложек под текстом, нечитаемого тёмного текста на тёмном;
   - нет градиентов и скруглений;
   - `document.documentElement.scrollWidth === innerWidth` на 375 px;
   - консоль без ошибок.
4. Главная выглядит как до шага.
5. В описании PR перечислить, что проверено и что нет.
